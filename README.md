# Gestão Mídia Pro Dashboard

Dashboard interativo para gestão de cronograma de mídia com integração com Excel.

## 🚀 Funcionalidades

- **Dashboard Principal**: Cards com métricas chave, gráficos de investimento mensal e distribuição por veículo
- **Cronograma Completo**: Visualização detalhada de todas as ações de mídia
- **Análises Avançadas**: Gráficos de sazonalidade e top veículos
- **Integração com Excel**: Upload de planilhas para atualização automática
- **Exportação**: Download de relatórios em CSV

## 📋 Requisitos

- Python 3.8+
- Dependências listadas em `requirements.txt`
